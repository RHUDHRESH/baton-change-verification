# Goal-agent reuse audit

Audit date: 19 October 2026. This records **20 additional, unique repositories** beyond the earlier Swarm, smolagents, Deep Agents, Graphiti, FalkorDB SDK/MCP and AG-UI references. Each commit link pins the reviewed material. A source-file review is distinguished from a README-level review. None of these 20 frameworks was installed or imported into the runtime, and no code from them was copied. Their patterns informed review and design; the table does not claim 20 shipped integrations or features.

The implementation under review uses the existing Python, Groq and FalkorDB stack. A model interprets a free-text goal, chooses evidence investigations, proposes a variable step DAG, and selects a graph-ready next action after observations. Deterministic code validates provenance, permissions, dependencies and receipts. Contract tests establish these boundaries; successful live goals and independent action receipts are separate acceptance evidence.

## License resolutions and reuse boundary

Repository API labels such as `NOASSERTION` were not treated as license decisions. The pinned MCP licenses describe a transition: new/consented code is Apache-2.0, unconsented original contributions remain MIT, and nonspecification documentation is CC-BY-4.0. AutoGen's root license covers documentation under CC-BY-4.0; its inspected AgentChat package has a separate MIT `LICENSE-CODE`. Anthropic's inspected skill-creator has Apache-2.0 terms, while [document skills have separate source-available/service terms](https://github.com/anthropics/skills/blob/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/docx/LICENSE.txt). Those document skills are not reused. This audit does not assign one blanket license to mixed repositories or to this application's original code. Existing third-party notices remain authoritative for vendored material.

## What is concrete in this application

`goal_agent.py` owns semantic goal interpretation, evidence-conditioned proposals and next-action selection. `goal_contract.py` validates the generated structure, capability arguments, inspected citations, DAG shape and relevant evidence seal; it does not choose the user's plan. `goal_graph.py` persists goals, plan revisions, steps, source bindings, actual episodes and receipts in FalkorDB. `HAS_STEP`, `DEPENDS_ON`, `CITES`, `OBSERVED` and `SUPERSEDES` participate in restart/readiness and freshness checks. `goal_actions.py` adapts approved publication and the existing verification capability. `web/goal-agent.js` presents the generated plan and actual events.

No new embedding provider or paid service is required. Retrieval uses bounded lexical candidates and directed graph neighborhoods; Groq supplies semantic interpretation and decisions. Removing AI blocks planning; removing required graph evidence/dependencies blocks action. The earlier fixed release matrix remains one bounded capability, not the semantic planner. Provenance/schema tests do not establish useful planning, semantic entailment, general company understanding or superiority over other systems. Ten composer examples, if shown, are inputs to the same interface, not ten independently validated features.
