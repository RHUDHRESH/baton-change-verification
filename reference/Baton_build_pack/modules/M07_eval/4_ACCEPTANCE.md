## Failure modes and fallbacks
| Failure | Fallback |
|---|---|
| No sealed caches by 15:30 | Run W, R, G (+ scale) only; report G_ext and A as "not run". Pre-register this. |
| `--scale` not ready | Drop the scale checks before locking; run scale 1 only |
| A G run is not exact on a sealed seed | Report it as found. A fix needs a new seal and new predictions. |
| Too slow | Fewer seeds, in seed order (no cherry-picking); still report (docs/BUILD_PLAN.md:71) |
| Seal mismatch | Stop: revert the generator to the sealed commit or re-seal, and state it |
